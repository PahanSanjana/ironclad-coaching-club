# Ironclad Coaching Club

Act like a senior frontend developer, expert React engineer, and world-class UI/UX designer specializing in modern fitness, bodybuilding, and personal training websites.

Your goal is to build a premium, visually stunning, fully responsive bodybuilding and personal coaching website that attracts potential clients, builds trust, and converts visitors into paying online coaching customers.

TASK:
Create a complete frontend website using React for a professional bodybuilding coach and personal trainer. The coach's personal information, name, biography, contact details, and achievements are not yet available. Use realistic dummy information and professional fitness photography as placeholders. Structure the code so these details can easily be replaced later.

STEP 1 – DESIGN DIRECTION
- Create a premium, modern, masculine bodybuilding aesthetic.
- Use a dark theme with black, charcoal, white, and bold red or gold accents.
- Use powerful typography, large fitness photographs, clean layouts, and subtle animations.
- Make the design look like a professional international fitness coaching brand.

STEP 2 – WEBSITE STRUCTURE
Create the following sections:

1. HERO: Powerful headline, coach introduction, professional bodybuilding background image, and prominent "Start Your Transformation" CTA.
2. ABOUT THE COACH: Dummy profile, experience, qualifications, achievements, and coaching philosophy.
3. COACHING GOALS: Fat loss, body transformation, muscle building, strength development, beginner fitness, bodybuilding preparation, and competition preparation.
4. COACHING PACKAGES:

BASIC – LKR 15,000 / 4 Weeks
- Personalized workout plan
- Nutrition guidance
- Weekly progress check-in
- Weight tracking
- WhatsApp support

PRO – LKR 20,000 / 4 Weeks
- Customized workout plan
- Personalized diet plan
- Weekly progress monitoring
- Workout and diet adjustments
- Exercise technique video feedback
- WhatsApp coaching support

ELITE 1-TO-1 – LKR 30,000 / 4 Weeks
- Fully personalized training and nutrition plan
- Weekly detailed progress assessment
- Training and diet adjustments
- Exercise technique video analysis
- Daily coaching support
- Priority WhatsApp support
- Bodybuilding contest preparation
- Posing guidance for competitors

Highlight PRO as the recommended package and ELITE as the premium package.

5. TRANSFORMATION GALLERY: Before-and-after fitness photos using dummy images.
6. TESTIMONIALS: Realistic placeholder client reviews.
7. FAQ: Coaching, payments, packages, and getting started.
8. CONTACT: WhatsApp CTA, social media links, and contact form.
9. FOOTER: Branding, navigation, and social links.

STEP 3 – TECHNICAL REQUIREMENTS
- Use React with reusable components.
- Use clean, maintainable code and organized project structure.
- Use Lucide icons where appropriate.
- Ensure complete mobile, tablet, and desktop responsiveness.
- Add smooth scrolling and subtle hover animations.
- Use high-quality royalty-free fitness images from reliable image sources.
- Make WhatsApp buttons functional using a placeholder phone number.
- Use dummy content wherever coach-specific information is unavailable.

STEP 4 – QUALITY CHECK
Verify the layout, responsiveness, navigation, visual consistency, and functionality of all interactive elements.

Avoid generic templates. The final website should feel like a premium bodybuilding coaching brand, inspire confidence, and encourage visitors to purchase a coaching package.

Take a deep breath and work on this problem step-by-step.
